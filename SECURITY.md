# Security Policy

## Supported Versions
Security updates are actively maintained on the latest release of the default branch across repositories.

## Reporting a Vulnerability
We take security vulnerabilities seriously. If you discover a security vulnerability, please do NOT create a public issue.

Instead, please report security concerns privately via:
* GitHub Private Vulnerability Reporting on the affected repository (if enabled), or
* Direct email to: **pavanbadempet@gmail.com**

Please include:
* Description of the vulnerability and its potential impact.
* Steps to reproduce or proof-of-concept.
* Suggested remediation or fix, if known.

You will receive an acknowledgment within 48 hours and regular updates until resolution.
