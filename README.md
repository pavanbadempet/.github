# .github

This repository contains central community health files, default community configurations, and global GitHub Sponsors funding configuration for [@pavanbadempet](https://github.com/pavanbadempet).

## Community Health & Sponsorship Defaults

- **Funding Configuration**: `.github/FUNDING.yml` establishes account-wide GitHub Sponsors funding for `@pavanbadempet`.
- **Global Inheritance**: Any public repository owned by `@pavanbadempet` inherits these community defaults when not overridden locally.
